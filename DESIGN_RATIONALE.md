# Design rationale (submission draft)

CampusCue is a lightweight deadline organiser for college students who juggle assignments, lab work, projects, and exam preparation. Its goal is to reduce the mental load of remembering every deadline and make the next action easier to identify. The interface uses a dark, high-contrast palette with mint accents to create a focused visual hierarchy without relying on decorative imagery. The task form stays beside the task list on desktop and stacks above it on mobile, keeping the main flow easy to find at different screen sizes. Deadline labels, priority markers, filters, completion controls, and a short “next best step” panel make the service useful immediately. Tasks are stored in the browser so the demo works without accounts, credentials, or a backend. A future improvement would be optional reminders and secure cross-device sync, introduced only after adding a suitable backend and clear privacy controls.
