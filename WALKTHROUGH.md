# CampusCue walkthrough (1–2 minutes)

Record your screen after testing the site locally or at the verified public URL. Keep the browser window clear of private information. Do not claim features you have not tested.

## Suggested 75–100 second sequence

1. **0–15 seconds — Problem and audience:** “CampusCue is a lightweight deadline planner for college students who manage assignments, lab work, projects, and exam preparation. It keeps the core flow simple and requires no account.”
2. **15–35 seconds — Add a task:** Enter a clearly labelled sample task, choose a due date, category, and priority, then select **Add to my plan**. Show the success feedback and updated task list.
3. **35–55 seconds — Prioritisation:** Point out the deadline label, priority indicator, summary counts, and “Your next best step” panel. Explain that the suggestion is a simple due-date/priority heuristic.
4. **55–75 seconds — Interactions:** Switch between All, Active, and Done. Mark a task complete, undo it, and delete a task. If you demonstrate **Clear completed**, use a completed sample and confirm the browser prompt.
5. **75–90 seconds — Persistence and limitation:** Refresh the page to demonstrate local browser storage. State clearly that tasks stay in the current browser profile and do not sync to other devices.
6. **Final seconds — Handoff:** Briefly show the README and mention the public repository and deployment URLs only after they have been created and verified.
